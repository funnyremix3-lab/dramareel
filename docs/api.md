# Reel Drama — API Contract (v1)

Base URL: `https://api.<domain>/api/v1`. Swagger UI: `/api/docs` (disabled in production unless `SWAGGER_ENABLED=true`). This document is the contract; the generated OpenAPI spec must stay consistent with it.

## Conventions

**Auth.** `Authorization: Bearer <Supabase access token>`. The API verifies it against the Supabase JWKS, then maps `sub` to `users.auth_provider_id`. The first authenticated call auto-provisions the user, profile and wallet. The user id is **always** taken from the token, never from the body or query.

**Access levels used below:**
- `public`: no token needed.
- `user`: any signed-in user.
- `opt`: a token is optional, but the response is personalised when one is sent.
- `perm:x`: an admin permission is required.

**Errors.** Every error has this shape:
```json
{ "error": { "code": "EPISODE_LOCKED", "message": "Human readable", "details": {}, "requestId": "…" } }
```
Stable codes include `VALIDATION_FAILED`, `UNAUTHENTICATED`, `FORBIDDEN`, `NOT_FOUND`, `CONFLICT`, `RATE_LIMITED`, `EPISODE_LOCKED`, `INSUFFICIENT_COINS`, `REWARD_NOT_ELIGIBLE`, `PAYMENT_VERIFICATION_FAILED`, `ASSET_NOT_READY` and `INTERNAL`.

**Pagination.** Lists use cursors: `?limit=20&cursor=<opaque>` returns `{ "items": [...], "nextCursor": "…" | null }`. The maximum `limit` is 50. Admin tables also accept `?page=&pageSize=` and return `total`.

**Idempotency.** Mutations that move value accept an `Idempotency-Key` header (UUID) and also rely on server-derived keys. Replaying a request returns the original result.

**Localisation.** `Accept-Language: hi` or `en` selects translated titles and synopses, falling back to the drama's primary language.

**Headers.** `x-request-id` is echoed back or generated by the server. `x-app-version` and `x-platform` are logged and may be used to force an update.

**Rate limits** (per user, or per IP when anonymous):
- comments: 10/min
- reports: 10/hour
- reward claims: 20/hour
- purchase verification: 30/hour
- SSV callback: per-IP burst limit
- everything else: 120/min

## Viewer API

### Auth & me
| Method | Path | Access | Purpose |
|---|---|---|---|
| GET | `/me` | user | Profile, roles, wallet balance, active subscription, consent flags |
| PATCH | `/me/profile` | user | Display name, avatar key, locale |
| PUT | `/me/consents` | user | Analytics, ads personalisation, marketing, push |
| POST | `/me/device-tokens` | user | Register an FCM token `{ token, platform }` |
| DELETE | `/me/device-tokens/{token}` | user | Unregister a token |
| POST | `/me/avatar-upload-url` | user | Presigned PUT for an avatar (image/*, ≤ 2 MB) |
| DELETE | `/me` | user | Request account deletion (30-day grace period) |

Sign-up, sign-in, OTP and refresh happen against Supabase Auth from the client. The API has no password endpoints.

### Catalog
| Method | Path | Access | Purpose |
|---|---|---|---|
| GET | `/home` | opt | Rails: `featured` carousel, `trending`, `new`, `recommended`, `continueWatching`, plus sponsored-card slots |
| GET | `/categories` | public | Active categories with localised names |
| GET | `/dramas?category=&sort=trending\|new\|popular&cursor=` | public | Drama list |
| GET | `/dramas/search?q=&cursor=` | public | Title search, `q` 2–60 characters |
| GET | `/dramas/{id}` | opt | Detail: synopsis, poster, cast, tags, categories, episode count, `isFavorite`, `resume` |
| GET | `/dramas/{id}/episodes?cursor=` | opt | Ordered episodes, each with `{ number, title, durationSeconds, access, locked, unlockCoins }` |
| GET | `/feed?cursor=` | opt | Vertical home feed: one item per drama (drama + its first or resume episode) |

### Playback & progress
| Method | Path | Access | Purpose |
|---|---|---|---|
| GET | `/episodes/{id}/playback` | user | `200 { manifestUrl, renditions:[{name,height,bandwidth}], subtitles:[{lang,label,url}], expiresAt, resumePositionSeconds }`, or `403 EPISODE_LOCKED { unlockOptions: { coins, rewardedAd: { eligible, placementKey }, subscription: true } }` |
| PUT | `/episodes/{id}/progress` | user | `{ positionSeconds, completed }`. Upserts watch history. The client sends it every 15 s, and on pause and exit. |
| GET | `/me/history?cursor=` | user | Continue-watching list, latest first |
| DELETE | `/me/history/{episodeId}` | user | Remove an item |

Free episodes still require a token. That gives per-user progress and stops anonymous hot-linking. Guest browsing of the catalog is public.

### Engagement
| Method | Path | Access | Purpose |
|---|---|---|---|
| PUT / DELETE | `/episodes/{id}/like` | user | Like or unlike (idempotent) |
| PUT / DELETE | `/dramas/{id}/favorite` | user | Favourite or unfavourite |
| GET | `/me/favorites?cursor=` | user | My list |
| GET | `/episodes/{id}/comments?cursor=` | opt | Visible comments, excluding users I have blocked |
| POST | `/episodes/{id}/comments` | user | `{ body (1–500), parentId? }`. Sanitised and profanity-checked. |
| DELETE | `/comments/{id}` | user | Delete own comment |
| POST | `/comments/{id}/reports` | user | `{ reason: SPAM\|ABUSE\|HATE\|SEXUAL\|OTHER, details? }`. Auto-hides the comment at a configurable report threshold. |
| PUT / DELETE | `/users/{id}/block` | user | Block or unblock a commenter |

### Wallet, unlocks & rewards
| Method | Path | Access | Purpose |
|---|---|---|---|
| GET | `/wallet` | user | `{ balance }` |
| GET | `/wallet/transactions?cursor=` | user | Ledger history |
| POST | `/episodes/{id}/unlock` | user | `{ method: "COINS" }` spends coins atomically. Returns `{ unlocked, balance }`. `409 INSUFFICIENT_COINS`. |
| POST | `/rewards/claims` | user | `{ placementKey, purpose: COINS\|EPISODE_UNLOCK, episodeId? }` returns `{ claimId, nonce, adUnitId, expiresAt }` or `422 REWARD_NOT_ELIGIBLE` |
| GET | `/rewards/claims/{id}` | user | `{ status: PENDING\|GRANTED\|REJECTED\|EXPIRED, coins?, episodeUnlocked? }` |

### Store
| Method | Path | Access | Purpose |
|---|---|---|---|
| GET | `/products?platform=ANDROID` | public | Active coin packs and subscription plans (SKUs) |
| POST | `/payments/google-play/verify` | user | `{ sku, purchaseToken }`. Verifies with Google, fulfils and acknowledges. Returns `{ payment, balance?, subscription? }`. |
| POST | `/payments/app-store/verify` | user | Same flow for iOS (later phase) |
| GET | `/me/subscription` | user | Current entitlement |

### Ads
| Method | Path | Access | Purpose |
|---|---|---|---|
| GET | `/ads/config?platform=` | opt | Active placements with ad unit IDs and frequency rules. Returns `adFree: true` for ad-free subscribers. |
| GET | `/ads/serve?placement=&platform=` | opt | Direct campaign creative `{ serveId, creative: { mediaUrl, headline, cta, label }, clickUrl }`, or `204` |
| POST | `/ads/impressions` | opt | `{ serveId }`. Deduplicated by `serveId`. |
| POST | `/ads/clicks` | opt | `{ serveId }`. Returns `{ destinationUrl }`. |

### Inbound webhooks (no user token)
| Method | Path | Verification |
|---|---|---|
| GET | `/ads/admob/ssv` | ECDSA signature against Google's AdMob verifier keys, plus `transaction_id` uniqueness |
| POST | `/payments/google-play/rtdn` | Pub/Sub push with an OIDC JWT (audience and service account checked) |
| POST | `/internal/video-assets/{id}/events` | Not exposed publicly. Workers write to the DB and queue directly. |

### Health
`GET /health/live` checks the process. `GET /health/ready` checks the DB and Redis. Neither returns internal details.

## Admin API (`/admin/*`, admin roles only)

Every write goes to `audit_logs` with before and after values. Permissions are listed in brackets.

| Area | Endpoints |
|---|---|
| Dashboard | `GET /admin/overview`: DAU, plays, unlocks, coins issued and spent, reward claims, top dramas. `[analytics:read]` |
| Dramas | `GET/POST /admin/dramas`, `GET/PATCH/DELETE /admin/dramas/{id}`, `POST /admin/dramas/{id}/publish|unpublish|archive`, `PUT /admin/dramas/{id}/translations/{lang}`, `POST /admin/dramas/{id}/poster-upload-url`. `[dramas:read/write/publish]` |
| Episodes | `GET/POST /admin/dramas/{id}/episodes` (single season 1 is created automatically), `PATCH/DELETE /admin/episodes/{id}`, `POST /admin/episodes/{id}/publish|unpublish`. `[dramas:write]`; reordering and multi-season management are not implemented yet. |
| Video | `POST /admin/episodes/{id}/video-assets` (presigned upload), `POST /admin/video-assets/{id}/complete|retry`, `GET /admin/video-assets?status=&episodeId=`, `GET /admin/video-assets/{id}`, `PUT /admin/episodes/{id}/current-asset`. `[media:write]` |
| Subtitles | `GET /admin/episodes/{id}/subtitles`, `POST /admin/episodes/{id}/subtitles/upload-url` → PUT the .vtt → `POST /admin/episodes/{id}/subtitles` (verifies WEBVTT, creates the row), `DELETE /admin/subtitles/{id}`. `[media:write]` |
| Taxonomy | CRUD `/admin/categories`, `/admin/languages`. `[dramas:write]` |
| Monetisation | `PATCH /admin/episodes/{id}/access` (FREE/PREMIUM, coins), `PATCH /admin/dramas/{id}/pricing`, CRUD `/admin/products`. `[monetization:write]` |
| Users | `GET /admin/users?q=`, `GET /admin/users/{id}` (profile, wallet, unlocks, payments), `POST /admin/users/{id}/suspend\|reinstate`, `POST /admin/users/{id}/wallet-adjustments { amount, note }`. `[users:read/write]`, `[wallet:adjust]` (Owner only) |
| Moderation | `GET /admin/moderation/comments?status=&reported=true`, `POST /admin/comments/{id}/hide\|restore\|delete`, `POST /admin/reports/{id}/resolve`. `[moderation:write]` |
| Ad config | `GET /admin/ads/placements`, `PATCH /admin/ads/placements/{key}`, `PUT /admin/ads/placements/{key}/configurations`, `GET /admin/ads/network-reports?from=&to=`, `POST /admin/ads/network-reports/import`. `[ads:read/write]` |
| Campaigns | `GET/POST /admin/ads/campaigns`, `GET/PUT /admin/ads/campaigns/{id}`, `POST /admin/ads/campaigns/{id}/schedule|activate|pause|complete|cancel`, `POST /admin/ads/campaigns/{id}/creative-upload-url` → PUT image → `POST /admin/ads/campaigns/{id}/creatives`, `POST /admin/ads/creatives/{id}/review` (not by the campaign creator unless owner), `GET /admin/ads/campaigns/{id}/report?from=&to=`. `[ads:read/write]` |
| Notifications | `GET/POST /admin/notifications`, `POST /admin/notifications/{id}/schedule|cancel`. Sending is done by `workers/notifications`. `[notifications:write]` |
| Reports | `GET /admin/reports/{kind}.csv?from=&to=` for plays, revenue-direct, revenue-network, rewards and users. `[analytics:read]` |
| Access control | `GET/POST/PATCH /admin/roles`, `PUT /admin/users/{id}/roles`. `[roles:write]` (Owner only) |
| Audit | `GET /admin/audit-logs?actor=&entityType=&entityId=&from=&to=`. `[audit:read]` |

Implemented routes are listed in Swagger (`/api/docs`, tag `admin: *`). Pricing fields (episode access/unlock coins, free episode count, default unlock coins) additionally require `monetization:write`. Campaign status moves DRAFT→SCHEDULED/ACTIVE→PAUSED→COMPLETED/CANCELED; activation needs an approved creative. Products: `GET/PUT /admin/products` (`monetization:write`).

### Default role permissions
| Role | Permissions |
|---|---|
| OWNER | `*` |
| CONTENT_MANAGER | `dramas:*` (read/write/publish), `media:write`, `monetization:write`, `moderation:write`, `analytics:read`, `notifications:write` |
| ADS_MANAGER | `ads:*`, `analytics:read` |
| SUPPORT_AGENT | `users:read`, `users:suspend`, `moderation:write`, `audit:read` |
